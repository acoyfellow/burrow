coil: video storyboard

About 75 seconds, a 2:1 frame, no voiceover. Frames use existing coil screenshots as stand-ins. The real recording will be a new run.

The one idea: you and the agent use the same computer. You type in its terminal and click in its browser while it works.

1 Title card

The wordmark on the dark tile with the faint loops pattern. Hold for 3 seconds, no motion.

Files: docs/brand/coil-wordmark.svg and docs/brand/patterns/loops-dark.svg.

Every thread gets its own computer.

2 The prompt

A new thread. Type "Build a counter page with a + button, serve it on localhost:3000, and commit it," then send it.

Use a fresh thread name so the sidebar is nearly empty.

The agent works in a real shell.

3 The agent works

Tool calls stream in: write_file, the server starting, git commit.

Sped up 2×. A "2×" label stays in the corner for the whole section.

You get a terminal on the same machine.
0:22–0:32
4 You join the shell

Click + to open a terminal. Type ls and git log --oneline -1. The agent's file and commit are there.

Its browser opens its localhost.
0:32–0:45
5 You click the page

Open the browser tab at localhost:3000. The counter loads. You click + twice and it shows 2.

Turn on a cursor highlight so your clicks are easy to see.

You both drive the same page.
0:45–0:55
6 The agent clicks too

Send "Click + three more times and tell me the number." Its clicks show on the same live page. It replies 5.

The most important shot. If the agent says the wrong number, record it again. Never edit the number.

Pause saves the disk. The next message brings it back.

Fork starts a new thread from this disk.

The wordmark, one line of text and the repo link, on the same background as shot 1.

Why this order

  • Shots 2 and 3 show the agent working, which every demo shows.
  • Shots 4 to 6 (orange border) are the part only coil does. The counter going from 2 to 5 shows that you share one browser, which a screenshot cannot show.
  • Shots 7 and 8 answer "what happens to the computer". Keep them short.

Look

  • Use the brand kit in docs/brand/. Orange #F38020 on #141416, Google Sans Flex for captions, and 600 weight, never bold.
  • Captions are sentence case, one line, with no full stop unless there are two sentences.
  • Use the app's dark theme in every recorded shot so the cuts to the title and end cards match.
